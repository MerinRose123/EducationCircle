# EducationCircle

Running in local

create a virtual environment in which the dependencies should be installed.
Type the following commands in the terminal where the project is situated.( EduCircle)
1. `cd EduCircleBackend`
2. `pip install -r requirements.txt`
3. `python manage.py migrate`
4. `python manage.py runserver`
5. Load the default fixtures which will add default categories, exam types as well as sample questions.
`chmod +x populate_data.sh`
`./populate_data.sh`
